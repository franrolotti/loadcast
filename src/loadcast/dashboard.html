loadcast · live day-ahead load forecasts

Every day at 09:00 UTC each model forecasts tomorrow's hourly electricity load, using the weather forecast available at that time, and is scored against ENTSO-E actuals and the TSO's own forecast. Code & method

Models and runs

Each training run is a separate set of models. Solid: newest run of a model; dashed and dotted: older runs. Runs listed in live.yaml forecast every day; the others are kept for comparison.
